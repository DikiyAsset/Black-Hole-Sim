# BlackholeSim

Пиксельная визуализация чёрной дыры на Python, Pygame и NumPy. Показывает светящийся газовый диск, искажение света и сетку пространства. Чёрную дыру можно осматривать с разных сторон.Лучшая среди других

## Запуск

Открой терминал в папке `BlackholeSim` и выполни:

```powershell
python -m pip install "pygame>=2.6,<3" "numpy>=2.1,<3"
python VOID.py
```

Устанавливать зависимости нужно только один раз.

## Управление

| Кнопка | Действие |
| --- | --- |
| Правая кнопка мыши + движение | Повернуть камеру вокруг чёрной дыры |
| Колесо мыши | Приблизить или отдалить |
| Пробел | Пауза / продолжить |
| R | Сбросить время анимации |
| G | Показать / скрыть сетку |
| 1 | Обычный ракурс |
| 2 | Вид сбоку, почти в плоскости диска |
| 3 | Вид сверху |
| F11 | Полноэкранный режим / окно |
| Esc | Закрыть симуляцию |

## Файлы

- `VOID.py` — запуск, окно, камера и управление.
- `renderer.py` — расчёт изображения чёрной дыры, диска и искажения света.
